# Portfolio (Astro)
`npm install && npm run dev` to preview, `npm run build` to produce `dist/`.
- Personal info, links, skills: `src/data/site.ts`
- Add a project: copy `src/content/projects/fairshots.md`, change the frontmatter and text.
- Add media: drop files in `public/media/<project>/`, set `hero:` or use normal Markdown images. `.webm`/`.mp4` clips go in `hero:` and autoplay muted.
- Diagrams: write a mermaid code block in any project file.
- Search the project for `TODO` to find what still needs filling in.
